# 🍳 Cook It

Cook It is a modern Android cooking app built with **Kotlin** and **Jetpack Compose**.

The app allows users to browse meal categories and explore meals based on the selected category using data from **TheMealDB API**.

## ✨ Features

* Browse meal categories
* Select a category to view its meals
* Display meals in a grid layout
* Load meal data from TheMealDB API
* Modern UI built with Jetpack Compose
* Remote image loading with Coil

## 🛠️ Tech Stack

* **Kotlin**
* **Jetpack Compose**
* **Material 3**
* **Retrofit**
* **Gson**
* **Coil**
* **Coroutines**
* **TheMealDB API**

## 🌐 API

This project uses [TheMealDB](https://www.themealdb.com/) to retrieve meal categories and meal information.

Base URL:

```text
https://www.themealdb.com/api/json/v1/1/
```

## 📱 App Flow

```text
Categories
    ↓
Select a Category
    ↓
Load Meals
    ↓
Display Meals in Grid
```

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/mahmoudragap77/Cook_It.git
```

2. Open the project in **Android Studio**.

3. Sync the Gradle files.

4. Run the app on an Android emulator or physical device.
